A fix for **Resident Evil materials**: textures now load for the RE Engine games.

## What changed
- **Materials files are read with the right layout.** An `.mdf2` file's layout depends on the version in its file name (`.mdf2.19` for Resident Evil Village, `.mdf2.32` for Resident Evil 4...). Dark STL took that number from a field inside the file instead, which the games fill with 1, so every real materials file failed with *String at offset ... runs past the end of the file* and the model showed without textures. The first test on a real Village weapon (`it02_022_shotgun_03`) found it; thank you.

## Windows
- **`DarkSTL_0.17.2_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.17.2_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.17.2-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```
