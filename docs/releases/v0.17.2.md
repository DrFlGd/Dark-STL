Cyberpunk 2077 models **open quickly** again, a big library no longer keeps a model waiting behind its previews, **Collect** shows how far it has got, and the library is **listed as soon as the app opens**.

## What changed
- **Cyberpunk models opened slowly.** A model's materials and textures are looked for in all of the game's archives (Cyberpunk has 50 or more), but only 16 archive indexes were kept in memory. Every lookup read the others from disk again, one after another, so opening a model (or drawing its preview) could take minutes. Every archive of the game now stays open, and the indexes are read about ten times faster and take far less memory. A test with 40 archives went from 2,172 index reads to 40.
- **Model names from the archives stay known.** The names learned while scanning were lost along with the archives that had been let go, so some models could show a hash instead of a name.
- **Opening a model goes ahead of the previews.** Previews now have their own workers in the engine, so a page of cards waiting for previews can't use all of the workers that opening a model needs. While a model opens, no new preview starts and those being drawn pause until it's open.
- **Collect shows its progress.** Working out what to copy for a whole game reads every model to find the textures it takes from elsewhere, which can take minutes, and the dialog only said "Working out what to copy…". It now runs as a job in the status bar, with the model it's reading and how far it has got, and you can stop it. Changing an option or closing the dialog stops the one before (they used to keep running, one more each time, and slowed everything down). Previews wait while it runs, *Copy* uses the plan already worked out instead of reading every model again, and each model's textures are remembered for the whole game, not only the first 4,096 models.
- **The library is there when the app opens.** At start-up every game folder was scanned again before anything was listed. What each folder's last scan found is now kept, so the games and their models are listed straight away, and the folders are scanned again behind them (each one's listing is replaced when it's done, so new files still show up). The first start after an update scans as before.
- **Big libraries respond faster.** With 95,000 models, the library summary took about 1.5 seconds to work out, and opening a model waited for it to finish. It now takes about 0.1 seconds, and searching or listing a category is about six times quicker.

## Windows
- **`DarkSTL_0.17.2_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.17.2_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.
