**Models are listed by the names the game gives them, and one search looks through every game.**

## What changed
- **In-game names.** FromSoftware models now show the name the game uses: *Uchigatana* rather than *Weapon 0400*, *Knight Helm* rather than *Head 1000 (Male)*, *Hollow Soldier* rather than *Character c1100*. Dark STL reads them from the game's own item text and item tables (the `msg` folder and the game's param files, or Dark Souls III's `Data0.bdt` and Elden Ring's `regulation.bin`). The file's name is still shown, muted, under the model's name, and a name you give a model yourself still comes first. A weapon takes the name of its plain version, not its +1 or infused copies; a character takes the name most of its entries give it.
- **Read in-game names.** A game's ⋯ menu has *Read in-game names*, which reads them again (after a game update, or after adding the text files to an extracted folder). *Unpack…* now also writes the text and tables the names come from.
- **Names stay after uninstalling.** They're kept in the game's library, and collected packages keep them too, so a collected copy is named even on another computer.
- **One search across every game.** The search box at the top of the menu (and on Home) looks through every game in the library by name, in-game name and file name. Press `/` to start typing a search (on a game's page it searches that page first, with a link to search every game). Results are grouped by game, and chips narrow them by game, kind, has animations, has textures, a triangle range, and collected or not.
- **List view columns.** The list view shows each model's name, kind, size, triangles, parts, textures, whether it has animations and whether it's collected (and its game when searching every game). Click a column's header to sort by it, and again for the other way. Each page remembers its own sort.
- **Sizes and counts on the cards.** A card's second line shows the model's size and triangle count, for example *1,234 mm · 12.3k triangles*, with everything else known in its tooltip. FromSoftware models and packages are measured in the background after a scan; other models are measured when their preview is drawn or they're opened.
- **Recent on Home.** Home shows the last eight models you opened, above the game tiles.
- Cyberpunk 2077, Borderlands, Returnal and the RE Engine games keep their file names for now: reading their names is planned.

Scanning isn't slowed: on a test folder of 3,000 weapon archives the scan took 0.09 s without names and 0.11 s with them, and the table of names is kept until the game's files change. Byte-built tests cover the text and table formats, each game's table layout, the search's filters and sorts, and the pages.
