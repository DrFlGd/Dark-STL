**Borderlands 3 and Wonderlands guns are put together from the games' own part lists**, and every unique gun gets its own configuration.

## What changed
- **Parts from the game's balances.** Every gun the game can drop has a balance listing all its parts by category (body, barrel, magazine, sight, grip, stock and their accessories). Dark STL now reads those lists from the paks (`RuntimePartList`, else the balance it builds on, else its part set). Each weapon type and maker's configuration (*Assault rifles Atlas (any parts)*...) offers exactly the parts the game uses, in the game's categories, and is no longer marked as guessed.
- **Unique guns.** Each unique or legendary gun with its own balance (Lyuda, Maggie, Big Deal...) is listed under its weapon type and maker as a configurable model of its own, with only the parts it can have.
- **Which mesh a part shows** is read from what the part's package imports, or the blueprint it imports, and otherwise matched by name (`Part_PS_JAK_Barrel_01` to `SK_PS_JAK_Barrel_01`). Parts that only change stats (most lettered accessories, elements, anointments) have no mesh, so they aren't offered.
- Weapon types and makers without balances (Borderlands 4, or a folder of extracted meshes) are still grouped from the meshes' names, as before.

Built and tested on synthetic paks made to the layouts BLCM documents; not yet checked on the games' own files. Gun skins (material parts) for these games aren't offered yet.

## Windows
- **`DarkSTL_0.19.0_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.19.0_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.19.0-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```
