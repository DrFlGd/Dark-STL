**Importing a game as model packages is several times faster.**

## What changed
- **Textures are stored as the game keeps them.** Collect › Model packages now keeps FromSoftware and RE Engine textures as DDS files, still compressed, instead of decoding each one and saving it again as a PNG. That took most of the time for models with many textures, and the DDS files are about half the size. Packages written before keep their PNG textures, and both open the same way.
- **Animations are sampled all at once.** Each animation's frames are worked out together rather than one by one, about 16 times faster, with identical poses. They are also compressed a little less, which takes half the time and makes them 1% larger.
- **Folders are listed once.** A game's folders can hold thousands of files, and each model's folder used to be looked through several times. During an import each folder is now listed once, and each model file is read once.
- **Four models at a time.** FromSoftware models are imported four at a time.
- **The asset store's index is saved every few seconds** instead of after every model.
- **Cancel stops an import.** In the Collect dialog, Cancel now stops the import (or copy). The models imported so far are kept and listed, and importing again carries on from there. **Run in background** closes the dialog and leaves the import running, shown at the bottom right. Unpacking a game's archives works the same way.

On 12 Bloodborne characters (real model files, each with 30 animations), the import took 38 s instead of 138 s, and wrote 36 MB instead of 42 MB.

## Windows
- **`DarkSTL_0.32.0_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.32.0_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.
