**A search for tracking down Borderlands materials the app can't find, and parents of another material type.**

## What changed
- New command `darkstl find <game folder> <name>`: every package under the game folder that stores or references an object whose name contains `<name>`, with its type, its path in that package, the path Dark STL looks it up by, and its flags; also the packages that couldn't be read and why. With `-o found.txt` the list is also written to a file. On Windows, from the app's folder:

  ```
  engine\darkstl.exe find "C:\Program Files (x86)\Steam\steamapps\common\Borderlands 2" Mati_DahlEpicAR -o found.txt
  ```
- A skin's parent material is now also found when its copy is of another material type than the reference names (a `MaterialInstanceTimeVarying` or `Material` where a `MaterialInstanceConstant` is named).

Tested on synthetic packages.

## Windows
- **`DarkSTL_0.23.2_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.23.2_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.23.2-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```
