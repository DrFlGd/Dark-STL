**Borderlands 2 gun skins are found in more places**, and a model without textures now says why.

## What changed
- **Skins and textures cooked into other packages.** A skin's material instance, and the textures it uses, can be imported from a package that isn't a file of its own (`Common_GunMaterials...`): the game cooked copies of them into whichever packages use them. When an object isn't where its path says, Dark STL now looks it up in every package of the game folder (from the lists it keeps when scanning, so this costs one pass over that list the first time).
- **A skin without textures no longer blanks the gun.** If a chosen skin's textures still can't be found, the parts keep their own materials, and a note says which skin had none.
- **Why there are no textures.** When a model has no textures, the Textures tab now lists what each material points to (material instance, parent, each texture parameter and whether its texture was found) and the notes about textures, so it's clear where the trail ends.

The first start after updating rescans Borderlands folders once, because the package lists now include materials and textures. Tested on synthetic packages; not yet checked on the game's own files.

## Windows
- **`DarkSTL_0.19.1_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.19.1_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:
