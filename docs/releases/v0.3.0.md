Texture detail comes through more faithfully: normal maps are now turned into height across the whole model, with new options for upscaling, extra detail and per-material strength.

## What changed
- **Height is worked out on the model itself.** Before, each normal map was turned into height on its own texture and the pieces were patched together at the UV seams. Now one solve covers the whole surface, so there are no seams to patch and broad raised shapes (panels, fullers) keep their height. On a test bench with known relief this cut the error by 14 to 59 % on every test pattern. Generating 1M vertices takes about 28 s.
- **BC1 normal maps no longer tilt parts.** Compressed normal maps can't store "flat" exactly, and that small error used to add up into a slope across the whole part. It is now removed first.
- **Strength per material.** Each material in the Generate tab's list has its own strength, on top of the overall one.
- **New options under More settings:**
  - upsampling the normal map, guided by the colour texture or by an AI model
  - removing compression blocks, by smoothing or by an AI model
  - fine detail from the colour texture, in mm
  - the materials' tiled detail normal maps
  - specular/metallic edges as hints
  - "edge keeping"
  - the old per-texture method
- **AI models are your own.** Add an `.onnx` model with *Add a model…*; none are included. For normal maps, a model trained on them such as 4x-Normal-RG0 (CC0, openmodeldb.info) works best. Check a model's licence before sharing prints made with it. The Windows app runs models on the graphics card through DirectML.
- `python -m darkstl.bench` runs the test bench.

## Windows
- **`DarkSTL_0.3.0_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.3.0_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.
