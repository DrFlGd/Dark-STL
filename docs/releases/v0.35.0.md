**Models exported by FModel, UModel and Blender open in Dark STL, and can be imported as model packages.**

## What changed
- **glTF models.** `.gltf` files (with their `.bin` and pictures beside them) and `.glb` files are listed and opened, as Blender, FModel and most other tools export them. Each mesh is a part you can leave out, placed where the file puts it. A material's base colour texture is used as the colour map and its normal texture as the normal map. A model too big to be in metres is read as centimetres, and you can switch that off. Skinned meshes are shown in their bind pose.
- **PSK and PSKX models.** UModel's and FModel's exports of Unreal models (`.psk` skeletal meshes, `.pskx` static meshes) are listed and opened at their real size and the right way round, like the Unreal games' own models. Each material is a part. Its textures are found by name anywhere in the folder: from the material files the tools write beside the model (UModel's `.mat` and `.props.txt`, FModel's `.json`), and otherwise from texture names that resemble the material's (`MI_Sword_Blade` finds `T_Sword_Blade_D` and `T_Sword_Blade_N`). TGA, PNG and DDS textures are read.
- **Imported as model packages.** A folder of such exports is added like a game. Collect › Model packages writes its models as packages, so they open after the exports are deleted. DDS textures stay DDS.
- **Every picture in the folder.** The texture picker offers every picture in a folder of exported models, also those no material names, and *Every texture of the game* keeps them all.

What isn't read yet: a PSK's skeleton, PSA animations, and glTF animations, so these models can't be posed.

## Windows
- **`DarkSTL_0.35.0_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.35.0_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.35.0-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```
