**Borderlands 2 reads its packages compressed as a whole (Startup, Engine, Core...).**

## What changed
- Borderlands 2 ships its startup packages (`Startup.upk`, `Engine.upk`, `Core.upk`, `WillowGame.upk` and a few more, each with a `.uncompressed_size` file beside it) compressed from the first byte, not just after their header. Dark STL couldn't open them ("Unreal package version 0"), so whatever they hold was never found. That includes the shared gun materials such as `Common_GunMaterials.Materials.AssaultRifle.Mati_DahlEpicAR`, the parent of skins like Dahl Seraphim. They're now read like any other package, decompressing only the parts that are used.
- `darkstl find` searches them too. Use the app's Rescan on the game to list the models they hold.

Tested on synthetic packages compressed the same way (LZO and zlib).

## Windows
- **`DarkSTL_0.24.1_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.24.1_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.24.1-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```
