Dark STL now reads Capcom's RE Engine games: Resident Evil 2, 3, 4, 7 (the ray-tracing release) and Village, and Devil May Cry 5, next to the FromSoftware games and Cyberpunk 2077.

## What changed
- **Resident Evil games in the library.** *Add game folder…* recognises an RE Engine game by its executable, its name or its files, and lists its models by kind (characters by series or player/enemy, weapons, objects, map pieces) from the engine's folder layout under `natives/`. Everything after that works as for the other games: previews, the Mesh, Textures and Displace tabs, export and *Collect into the app*.
- **Extracted or still packed.** Add the folder a pak tool (REtool, ree-pak) extracted, or the game's own install folder with the game's file list (a `.list` file from the RE Engine modding community, the same the pak tools use) copied in beside the `.pak` archives: the models are then read straight from the archives (stored, deflate or zstd), without extracting anything. The folder's notes say when a list is missing, or when a game's archives are encrypted (Monster Hunter Wilds and later) and must be extracted first.
- **The formats.** `.mesh` models of every generation of the engine (RE2/DMC5, RE3, Village, the ray-tracing releases, Monster Hunter Rise, Street Fighter 6, RE4, Dragon's Dogma 2 and later), their `.mdf2` materials and `.tex` textures (any DXGI format the DDS reader knows, padded rows included). Resident Evil 4 keeps the most detailed geometry and the full-size textures under `natives/stm/streaming/`; both are picked up when present, and the model says so when the streamed half is missing. Normal maps are taken as the engine makes them, green pointing up (OpenGL).
- **Collect** copies a model's mesh, its streamed half, its materials file and every texture it uses (small and streamed copies) with their paths below `natives/`, so the collected copy opens on its own.
- Command line: `darkstl info` describes `.mesh`, `.tex`, `.mdf2` and `.pak` files; `darkstl textures` writes a `.tex` file as PNG.

## Not yet
- Real game files: the readers follow the formats as the modding community documented them and pass on synthetic files; checking them on real Resident Evil files is next.
- Paks with an encrypted table of contents, GDeflate textures (Monster Hunter Wilds and later), MPLY stage meshes, blend shapes and posing RE Engine characters.

## Windows
- **`DarkSTL_0.8.0_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.8.0_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.8.0-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```
