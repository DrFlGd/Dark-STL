The Resident Evil games now open **straight from their install folder**: the community file lists that name the files in their `.pak` archives come with Dark STL, so there's no `.list` file to find and copy in any more.

## What changed
- **RE Engine file lists included.** Ekey's lists from [REE.PAK.Tool](https://github.com/Ekey/REE.PAK.Tool) for Resident Evil 2, 3 and 7 (the ray-tracing and the original releases), Resident Evil 4, Village and Devil May Cry 5 are bundled, cut down to the files Dark STL reads (meshes, textures and materials: 1.4 MB in all). Add the game's install folder and its models are listed from the paks. A `.list` file in the game's folder is still read as well, for files a game update added after these lists.
- The folder note for a pak no list names now says the game may have been updated and where newer lists are.

## Windows
- **`DarkSTL_0.12.1_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.12.1_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.12.1-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```
