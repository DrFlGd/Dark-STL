**Player suits show each texture set where it belongs.**

## What changed
- **Layered materials picked by UV tile.** Returnal's player suits (the first-person and house models, such as the Prototype suit) keep up to five texture sets in one material and put each part of the model in its own UV tile: tile 0 shows the first set, tile 1 the second, and so on. Dark STL showed the first set everywhere, which scrambled the suit. Each triangle now shows the set for the tile it sits in.
- **One rule for every layered material.** Dark STL reads how a material picks its layers: by vertex colour when the material says so (Alex in 0.41.0), otherwise by UV tile when the model's UVs are laid out that way. It isn't a fix for one model: every model built either way is covered. A model whose UVs only repeat a texture keeps its own textures as before.
- The Textures tab says where each layer shows, for example *shown on the triangles whose UVs sit in tile 2*.

Checked on Jerred's exported Prototype suit (all 169,541 of the suit's triangles land on one of its five texture sets) and on Alex (unchanged). Byte-built tests cover UV-tile layers and UVs that only repeat.

## Windows
- **`DarkSTL_0.42.0_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.42.0_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.
