**Collected Returnal keeps its type mappings, so it works with the game uninstalled.**

## What changed
- Collect now copies Returnal's type mappings (the `.usmap` the game folder or Settings has for it) into the collected copy as `Returnal.usmap`. It also writes down the engine release it read from the game's executable, in `Returnal\Binaries\engine-version.txt`. A collected Returnal then opens its models, materials and textures with the game uninstalled, like the other games since 0.26.0.

Tested by collecting a synthetic unversioned Returnal, moving the game away and comparing every model with what the game showed.

## Windows
- **`DarkSTL_0.26.3_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.26.3_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.
