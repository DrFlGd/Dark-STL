**Configurable models are imported as packages too.**

## What changed
- **Collect › Model packages** now also imports configurable models, such as Cyberpunk 2077 weapons with their attachments, and Borderlands 3, Wonderlands and Borderlands 4 guns with their parts. The base model, every part and every skin that can be chosen for it are written as packages, and the configurations are kept with them. With the game uninstalled, the Configure tab still offers every choice, made from the packages.
- A model that only a configuration uses (a Cyberpunk part's other appearance, say) is kept in its file's package without being listed as a model of its own, as in the game.
- Borderlands 2 guns whose skins are mixed for each part when they're shown, or read from another package, are still copied as game files. The Collect dialog says so.
- Models you combined into one are imported with their parts.
- A model file holding models named with slashes no longer fails to import.

This continues the model-package plan. Next: Borderlands 2 skins baked into packages, then the whole asset store.

Tested on synthetic files for all eight games: every configurable model, with each option of each slot chosen, shows the same from its packages with the game removed.

## Windows
- **`DarkSTL_0.31.0_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.31.0_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.31.0-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```
