**Returnal: the Hulk's animations, and player models' textures in the right places.**

## What changed
- **Animations that move a skeleton's virtual bones are read.** A skeleton can have virtual bones, which follow other bones (the Hulk has five that track its wrist and feet). Animations keep tracks for them, numbered after the real bones. Dark STL counted only the real bones, so it turned away 45 of the Hulk's 47 animations ("a track for a bone the skeleton doesn't have"). All 47 are now listed and pose the Hulk. The export report lists a skeleton's virtual bones.
- **Layered materials picked by vertex colour show each layer's own textures.** Returnal's player models (Alex, Selene) use one material that holds up to four texture sets: the kid's shirt, overalls, gear, and skin and hands. The game picks a set for each vertex by its vertex colour (none, red, green or blue). Dark STL put the first set on the whole body, which scrambled it. It now reads the mesh's vertex colours and the material's layer switches. Each part of the body gets its own layer's colour and normal maps, shown as materials named "… layer 1", "… layer 2" and so on.
- **A material slot with no material shows the material named after it.** Some meshes leave a slot empty because the game fills it while it runs: Alex's head and hair slots are *M_Helios_Head* and *M_Helios_hair*. Dark STL now looks for the game's material of that name and shows it, marked as guessed.
- **Collect takes every texture a material names.** It used to stop after 16 materials and textures per model, so a layered material lost some of its maps (Alex's overalls, gear and skin colour maps weren't collected). It now follows them all.

Checked on Jerred's exported Hulk, Spore Wizard and Alex files: all 47 Hulk animations read and pose, the Spore Wizard's 40 pose as before, and each of Alex's vertex colours lines up with its texture set. Byte-built tests cover virtual bones, vertex-colour layers, slots with no material, and Collect.
