**Borderlands 2 guns with skins are imported as model packages too.**

## What changed
- **Skins are kept as how they mix.** Most Borderlands 2 skins have no colour texture: the game mixes each part's colour from masks and zone colours. Until now, Collect › Model packages copied any gun with such a skin as game files. Now the skin's package keeps its colours and the masks they're mixed over, and each gun part's package keeps the texture coordinates the mix reads. The colour is mixed when it's shown, from the packages alone, and it comes out the same as from the game. So every Borderlands 2 gun opens with every skin after the game is uninstalled.
- **Borderlands 2 packages written before are written again.** Packages from 0.31 and 0.32 don't hold the skins' mixes, so the next Collect writes them again. Other games' packages are kept.
- **Importing again skips files that haven't changed inside archives.** A model stored inside a package or archive (Borderlands packages, Cyberpunk archives, Resident Evil and Unreal paks) was imported again on every Collect. Its package was compared with a path that isn't a file on disk. It's now compared with the archive the model is in, so importing again only writes what changed.
- **Borderlands 2 gun sizes are right.** A gun part read from the game kept the vertices of the parts it shares a mesh with, so the size shown in mm covered parts that weren't chosen. It now covers only the parts shown.

## Windows
- **`DarkSTL_0.33.0_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.33.0_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

pip install "dark_stl-0.33.0-py3-none-any.whl[gui,remesh,fast,ai]"
