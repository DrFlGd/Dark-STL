**Borderlands 2 gun skins open again**, from the base game and from DLCs.

## What changed
- **DLC packages belong to the game.** A DLC's packages (`<game>/DLC/<name>/...`) were treated as a game of their own, so anything they import from the base game wasn't found. Many gun part meshes are read from copies in DLC packages, which meant every skin lookup searched only that DLC's folder: "Skin: ... couldn't be opened (... wasn't found)". Lookups from a DLC package now search the whole install.
- **Skins remember their package file**, so a skin opens even when the gun's meshes come from another folder.

The first start after updating rescans Borderlands folders once. Tested on synthetic packages laid out like the game's DLC folders.

## Windows
- **`DarkSTL_0.19.3_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.19.3_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.19.3-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```
