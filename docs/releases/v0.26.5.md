**Returnal materials pick their own textures.**

## What changed
- Without the game's type mappings, a Returnal material instance's texture parameters are now picked out of its unnamed property values: each texture reference there follows the parameter's name (`BaseColor`, `Normal`, ...), so the textures get their roles from the material itself, not only from their file names.
- Texture names ending in `_BaseColor`, `_BC`, `_Normal` are recognised as colour and normal maps, and `_ORM`, `_MRA`, `_Roughness` as mask maps. Returnal's colour maps were named `_BaseColor` and weren't taken before, so most models showed no texture.
- Generic textures a master material layers over everything (noise, grunge, engine defaults, the texture library) are no longer taken for a model's colour or normal map by their names, so models stop showing a grunge texture as their colour.

Tested on synthetic unversioned Returnal packages (a material instance whose colour map has no role in its name).

## Windows
- **`DarkSTL_0.26.5_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.26.5_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.
