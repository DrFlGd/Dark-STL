A fix for **Cyberpunk 2077 libraries**, whose long depot folder names could fill more than half the window.

## What changed
- **Group chips keep to two rows.** Above a kind's models, the group chips now take at most two rows, each name cut short (the full name and count show on hover). *All N groups* opens the rest in a short scrolling box; *Fewer groups* closes it. The group you're looking at moves up next to *All*, so it is always in view. Every group is still listed in full in the Details panel on the right.
- **The model page's bar stays inside the window.** A long model or folder name used to push the title bar wider than the window. The breadcrumbs and file name now give way first, then the model's name is cut short (hover for the whole name; the File section on the right shows it in full).

## Windows
- **`DarkSTL_0.17.1_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.17.1_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.17.1-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```
