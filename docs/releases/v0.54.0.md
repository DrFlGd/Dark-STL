**DOOM: The Dark Ages's models, textures and animations, read straight from the game.**

## What changed
- **DOOM: The Dark Ages in the library.** Add the game's install folder as it is, as for DOOM Eternal: Dark STL reads the `.resources` containers and `.streamdb` files in `base` and lists the characters, demons, weapons, pickups, props and map pieces, grouped by their folders, with the textures their materials name.
- **Posing.** Skinned models come with their skeleton and every animation made for it on the Pose tab, including the longer animations the game keeps in its StreamDB files. Models that bend each vertex with six or eight joints keep the four that weigh most.
- **Oodle.** The Dark Ages compresses its files with Oodle but doesn't ship the library as a separate file (it's built into `DOOMTheDarkAges.exe`). When DOOM Eternal is installed beside it in the same Steam library, Dark STL uses Eternal's `oo2core_8_win64.dll` by itself; otherwise the folder says so, and *Settings › Game tools › Oodle* can point at an `oo2core_9_win64.dll` or Eternal's.
- **Collect works without the game.** *Game files* copies each model's resources and streamed pieces (animations included) decompressed, so the copy needs neither the game nor Oodle; model packages work as for every other game.
- **Still to be checked on the real game.** Everything was tested on synthetic files built to the published descriptions of the formats (Valen's), like DOOM Eternal in 0.53.0. Models are scaled from id units as inches; a game profile in the settings folder can change that (`{"format": 1, "name": "DOOM: The Dark Ages", "engine": "idtech", "idtech": {"unit": 0.01}}`, see docs/profiles.md). Vegetation and strand-hair models aren't read, and models are named by their file names for now.

DOOM (2016) and DOOM VFR follow once their files have been checked.

## Windows
- **`DarkSTL_0.54.0_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.54.0_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.54.0-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```
