**Grand Theft Auto III, Vice City and San Andreas open in Dark STL.**

## What changed
- **A new importer for the RenderWare GTA games (PC).** Add the game's install folder as it is. Dark STL reads the models (`.dff`) and their textures (`.txd`) straight from the `.img` archives (`gta3.img` with its `gta3.dir` in III and Vice City, the single-file archives in San Andreas) or from loose files. Nothing in the game's folder changes.
- **Sorted the way the game sorts them.** The game's own lists (`gta.dat`, `default.dat` and the `.ide` files they name) put each model under Characters (civilians, gangs, police, story characters...), Vehicles (cars, bikes, boats, helicopters, planes...), Weapons, Map Pieces (grouped by area) or Objects. They also say which dictionary each model's textures are in, with San Andreas' parent dictionaries and the shared `vehicle.txd` and `generic.txd`. Vehicles show their names from the game (Landstalker, not `landstal`).
- **Cars come out whole and in their colours.** The game keeps one wheel and copies it to each axle as it draws the car. Dark STL does the same, so every axle has its wheel. The damaged panels and the low-detail body are left out, and each can be turned back on. Every colour pair in `carcols.dat` is a variant of the car, with the paint baked into the textures, so packages and exports carry it.
- **Characters can be posed.** Peds are skinned meshes. The Pose tab offers the animations in the game's `ped.ifp` that move them (San Andreas' compressed animations included), and the walk's movement across the ground is taken out so the figure stays in place.
- **Collect and packages.** Collect copies a model, its texture dictionaries and animations out of the archives, plus the game's lists, colours and text. The collected copy opens and poses without the game. Packages work as for the other games.
- **Each game is a profile.** What differs between III, Vice City and San Andreas is a small JSON file. A file of the same name in the settings folder's `profiles` folder replaces it.
- A folder of `.dff` and `.txd` files exported with another tool opens too, with its textures looked up by name.

This has only been tested on synthetic files built byte by byte (a San Andreas and a GTA III folder with a car, a ped, a map object and their textures, colours, text and animations). Nothing has been checked against the real games yet.

## Windows
- **`DarkSTL_0.50.0_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.50.0_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.50.0-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```
