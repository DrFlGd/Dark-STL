**Borderlands 2 gun skins find their parent materials and textures.**

## What changed
- A skin's material instance (say `Mati_DahlCommonAR_Seraphim`) names a parent and textures in packages that aren't files of their own (`Common_GunMaterials...`). Copies of them are cooked into other packages, but not always under an outer marked as the original package, and not always under the groups the path names. Dark STL now also finds such a copy by its path inside the package that holds it, and then by its name and class (the copy whose path ends most like the one wanted).
- When a parent or texture still isn't found, the material's notes say how many packages, and which folder, were searched.

Tested on synthetic packages.

## Windows
- **`DarkSTL_0.22.2_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.22.2_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.22.2-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```
