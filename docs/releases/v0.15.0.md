Weapons and other models kept as a **body and separate parts** can now be put together in the app: a new **Configure** tab chooses a part for each slot (magazine, sight, barrel, stock...), and the model made goes through Mesh, Displace, Cut and Export like any other.

## What changed
- **Configurable models in the library.** Each one is listed beside the other models of its kind, its card saying *Configurable: N slots, M parts*. Searching for "configurable" finds them all.
- **Configure tab.** A configurable model opens on it: a list per slot (with *None* for slots that can be left empty), *Presets* that choose every slot at once, *Defaults*, and *Save as preset…*. Changing a part puts the model together again at once; the models it is made from stay open, so switching back and forth is quick. Each part is listed on the Model tab too, where it can be left out.
- **Edit… and Make configurable….** *Edit…* changes a configuration: its name, its slots, the parts each slot offers (*Add part…* searches the game's models), which is the default, and *Move* (mm) and *Turn* (degrees) for a part that isn't in place. *Make configurable…* in a model's More menu starts a configuration with that model as its base. What you make is kept in your own list (one file per game in the settings folder) and takes the place of the list it came from; *Remove* brings that one back.
- **Configuration lists per game.** What fits what comes from lists: shipped with the app, kept in a game folder (`*.darkstl-configs.json`), or your own. For Cyberpunk 2077 and the RE Engine games, weapons whose parts sit beside them in one folder are also guessed from their file names (marked *Guessed*). The format is in `docs/configurations.md`. Parts are placed in place, on a named point (socket) of the base or of another chosen part, and/or by an offset, turn and scale.
- **Collect.** Collecting a configurable model copies its base and every part that fits it.
- **For importers.** A new `configurations(folder, game, entries)` hook and `SourceModel.sockets`, for games whose files say what attaches where (the Borderlands importer will use them).

## Windows
- **`DarkSTL_0.15.0_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.15.0_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.15.0-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```
