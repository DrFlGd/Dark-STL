Dark STL now **unpacks the games itself**. Dark Souls (Prepare to Die Edition), Dark Souls II, Dark Souls III, Sekiro and Elden Ring keep their models in encrypted archives; there's no need for UXM Selective Unpacker or UDSFM any more: add the game's install folder as it is and choose *Unpack*.

## What changed
- **Unpack, in the app.** Adding a game folder whose models are still in its archives (`Data0.bhd`/`.bdt`, `GameDataEbl.bhd`, `dvdbnd0.bhd5` ...) goes straight on to the new *Unpack* dialog. It's also in the folder's menu, on the game's page, on Home and in *Settings > Game archives*. Choose what to unpack (characters, weapons and armour, objects and assets, map pieces, each with its file count and size) and where; Dark STL writes out only the models with their textures and animations, laid out as the game names them (`chr/`, `parts/`, `asset/` ...), and lists them straight away. Sound, scripts, collision and effects stay packed, so an Elden Ring unpack is a fraction of the full 50 GB.
- **The game's folder isn't changed.** Files go into the App library (`<library>/<game>/`, beside anything collected from that game; movable in Settings), with the game's Oodle library copied beside them, so the install can even be removed afterwards. Unpacking again only writes what isn't there yet.
- **How it works.** The archives' file lists are decrypted with the keys the games carry (Dark Souls II's from its own `.pem` files), once: the first time takes up to a minute for Elden Ring, then they're kept decrypted in the cache. Encrypted parts of files are decrypted as they're written. The archives only store a number for each file's name, so the names come from the community's file lists: UXM's (as Smithbox ships them) come with Dark STL, and *Download newer file lists* fetches UXM Selective Unpacker's newest, which also name Elden Ring's Shadow of the Erdtree files. Models a list leaves out are still found when their names follow the pattern of known ones (`c2010` → `c2011`), checked against the file's contents.
- **Dark Souls II** models (`c1000.bnd`, `wp_1000_m.bnd`, `o00_0002.bnd`) are now listed in its library.
- **Command line:** `darkstl unpack <game folder> -o <folder> [--only characters,parts,objects,maps] [--dry-run] [--download-lists]`.
- **Engine:** new `unpack_plan`, `unpack_run`, `filelists` and `filelists_download` commands; folders say whether they hold packed archives (`packed`). `cryptography` is a new dependency (included in the Windows app).

## Not yet
- Checked on synthetic archives built to the published format (encrypted with a test key), not yet on real game files. The keys themselves are the ones UXM and Smithbox use.
- Dark Souls II models and Dark Souls PTDE's split character textures are listed but unchecked on real files.

## Windows
- **`DarkSTL_0.12.0_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.12.0_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.12.0-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```
