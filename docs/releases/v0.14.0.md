Models can now be **made watertight** for printing: the whole model is wrapped into one solid, and the parts inside one another are removed.

## What changed
- **New Finish tab** for post-processing before printing, with **Make watertight**. Game models are built from parts that cross (an arm pushed into a sleeve, armour plates over a body, a head into a hood) and open surfaces (capes, cloth). Every part is made solid (small openings closed, open surfaces thickened) and they are all joined, so where parts cross, the surfaces inside are removed and only the outside stays, exactly as it was. No detail is lost.
- **Fill hollows sealed inside** (on by default): space that the parts shut in, such as under a closed coat or helmet, is filled, so the model is solid all through.
- **Close narrow gaps** (optional): bridges slits between parts (a sleeve around an arm) up to a width you choose. The bridges sit just under the surface everywhere else, so the outside keeps its detail. Fine grooves narrower than that width get filled too, so keep it small.
- **Remove loose bits** (optional): separate bits that don't touch the model and are smaller than a share of it.
- *Show › Finished* shows the watertight model. **Export › Finished** writes it, and **Cut › Finished** cuts it into pieces. Each result is kept, so switching between two settings is instant.
- Making a model solid (for Finish and for Cut) keeps more detail: parts that only touch at a corner are no longer treated as one broken part and rebuilt from voxels.
- Command line: `--watertight` on `export` and `enhance`, with `--close-gaps MM`, `--drop-loose PERCENT`, `--keep-hollows` and `--sheet MM`. It runs before `--cut` if both are given.

The watertight model has no textures, since it's made for printing. So far it has been tried on test models only, not yet on game characters. If a part comes out wrong, the model's name and the notes under the result help.

## Windows
- **`DarkSTL_0.14.0_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.14.0_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.14.0-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```
