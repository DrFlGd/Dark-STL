**Resident Evil characters kept as separate meshes are put together as one model**, and **the Pose tab says when a mesh can't bend**, as Village's gallery figures can't.

## What changed
- **Whole characters.** RE Engine games keep a character as one mesh per body part, each in its own folder (`ch03/0200/body/body00/ch03_0200_body00.mesh`, `.../face/face00/...`, `.../hair/hair00/...`). Each such character is now also listed as a configurable model (*ch03_0200 (whole character)*) in *Characters*: the body is the base, and every other part folder is a slot (Face, Hair...) whose first file is chosen; other body files are offered under *Body (other)*. The parts are modelled in place on the same skeleton, so they line up as they are.
- **One pose moves every part.** When a model made of several parts is posed, each part that has the same animation (a character's face and hair share the body's animation lists) is posed with it. Only parts without it stay where they are, as weapon attachments did before.
- **Figures that can't bend.** Village's gallery display models (`character/ch/prefab/gallery/...`) are baked into one piece bound to the hip bone (plus a bone per pouch), so no animation can bend their joints. The Pose tab and the model's notes now say so, and name the bones, instead of leaving the model moving as a block. For a figure that poses, open the character's own meshes (the whole-character model above).
- **"Moves N of M bones"** in the Pose list counts only bones whose motion shows on the mesh (the bones its vertices are weighted to and their parents), so a gallery figure shows *moves 2 of 56 bones* while the posable copy shows the real reach.
- Village characters' animations are filed under their own two-part id (`ch03_0200`), so a character gets its own lists first, then the rest of its series.

Checked on the ch03_0210 gallery figure and the ch03_0200 skinned mesh supplied; the whole-character assembly is built from the games' folder layout and synthetic files, not yet seen on a real character folder.

## Windows
- **`DarkSTL_0.19.2_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.19.2_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

pip install "dark_stl-0.19.2-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
