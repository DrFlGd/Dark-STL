**Painted 3MF, refined**: paint now splits triangles the way the slicers' own brushes and GusGusGooose do, and the palette ignores the blends between colours.

## What changed
- **Only the long sides of a piece are split.** A piece of a triangle that needs more colour detail is split across the sides longer than the smallest feature, not always into four: three long sides make four pieces, two make three, one makes two. This is how PrusaSlicer, Bambu Studio and OrcaSlicer split under their own paint brush, and how GusGusGooose paints inside faces. Long thin triangles, common in game meshes, now halve along their length instead of turning into ever thinner slivers. On Bloodborne's c1120 the paint looks the same with a quarter fewer pieces (4.9 million down to 3.7 million), so slicers load it faster.
- **The palette is learned from flat texels.** A texel whose neighbours differ from it, such as the blend along the border between two colours, no longer counts when the palette is chosen, so a blend can't take a filament slot from a real colour. Textures with almost no flat texels (noise) still use every texel. This is the rule GusGusGooose uses when it reduces a picture to filament colours.
- **Large triangles are read texel by texel for the palette.** The palette used to read at most 256 points on each triangle, which on a big triangle over a fine pattern could all land on the same blend. It now reads about one point per texel.

## Windows
- **`DarkSTL_0.22.1_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.22.1_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.22.1-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```
