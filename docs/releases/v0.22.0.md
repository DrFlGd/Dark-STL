**Painted 3MF**: a model is painted from its colour textures and written for a multi-colour printer, with the paint finer than the mesh's triangles.

## What changed
- **A new export format, Painted 3MF** (Export tab, or `darkstl export ... -o model.3mf`). The model's colour textures are reduced to a palette of 2 to 12 colours and every triangle is painted with them the way Bambu Studio, OrcaSlicer and PrusaSlicer store their own brush paint: a triangle whose colours differ is split into four at its edge midpoints, and so on, down to the smallest feature you ask for, so the colour borders run across the triangles rather than along them. Nothing is added to the mesh. The file opens with its colours in Bambu Studio and OrcaSlicer (`paint_color`) and PrusaSlicer (`slic3rpe:mmu_segmentation`); set each filament slot to the palette's colour, in order.
- **The palette** is suggested from the model: the colours that stand best for the texels its surface covers (k-means in Oklab, weighted by the surface each covers). Each swatch can be changed by hand, or the count changed and the colours suggested again. *Show the colours on the model* draws the 3D view's textures in the palette, as the print will be.
- **How fine** is set by the print height and the smallest colour feature in mm (150 mm and 0.5 mm by default): triangles are split only where colours meet, and never below that feature size or below a texel. *Clean-up* removes specks in the reduced textures that would be single dots of filament (light: under 4 texels; strong: under 24).
- The palette's colours are drawn, numbered by filament slot, in a `<name>_palette.png` beside the file, and listed in the file's metadata.
- The Enhanced (displaced) and Original models can be painted; the Finished model and cut pieces have no textures, so they can't.
- CLI: `--colours`, `--palette "#rrggbb,..."`, `--print-height`, `--feature`, `--cleanup` on `export` and `enhance`.

Checked on Bloodborne's c1120 (40,000 triangles: 18 s; enhanced to 746,000 triangles: 55 s) and o000612, against a reader written from Bambu Studio's own source; not yet opened in a slicer, so please tell me how it loads.

## Windows
- **`DarkSTL_0.22.0_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.22.0_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.22.0-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```
