The Windows app now comes with an AI upscaler for normal maps, so *Upsample the normal map: AI model* works straight away without finding, converting and adding a model yourself.

## What changed
- **Included AI upscalers.** RunDevelopment's [4x-Normal-RG0](https://github.com/RunDevelopment/ESRGAN-models/tree/main/normals) models, made for upscaling game normal maps, ship with the app: one trained on BC1-compressed textures (what Bloodborne uses) and one trained on BC7. They are licensed CC BY 4.0, so prints made with them can be shared freely. They are separate files in the app's `engine\models` folder (about 67 MB each, with their licence beside them), not part of `Dark STL.exe` or the engine program.
- **Picked for you.** In Generate > More settings > *Upsample the normal map*, choosing *AI model* now defaults to *Included (matched to each texture's compression)*: BC1, BC2 and BC3 textures get the BC1 model, everything else the BC7 one. Your own `.onnx` models are still listed and can be chosen instead. On the command line, `--upsample ai` uses the included models too unless `--ai-model` names another.
- **Keeps the texture's shape.** Upscalers tilt their output by a degree or two and bend broad slopes, which turned into slight bulges once the slopes were added up into heights. Now only the model's detail finer than the texture's own pixels is used, and the broader shape comes from the texture itself. This applies to models you add as well.
- **Only where it helps.** AI upscaling is skipped for a texture whose pixels are already closer together than the vertices (Generate step 2 says so), since the extra pixels couldn't show. That saves minutes on models with large textures.

## Speed
Without a graphics card AI upscaling is slow: about 30 to 45 seconds per 512 px texture on a 4-core processor, several minutes for a 2048 px one. On Windows it uses the graphics card through DirectML when there is one, which is much faster.

## Windows
- **`DarkSTL_0.5.0_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.5.0_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.5.0-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```

The wheel doesn't include the AI models. From a copy of the repository, `pip install onnx` and `python desktop/models/bundle.py <folder>` downloads and converts them; point `DARKSTL_BUNDLED_MODELS` at that folder to use them as the included ones.
