**Sharp textures for Borderlands DLC models.**

## What changed
- Borderlands 2 and The Pre-Sequel: a DLC's packages (Tiny Tina's Assault on Dragon Keep and the others) keep their large texture mips in the game's own texture caches (`.tfc`), not beside the DLC's packages. Dark STL only looked beside the package and in the folders just above it, so it fell back to the small mips stored in the package itself: a 2048 x 2048 texture was shown at 64 x 64 or so. It now looks through the whole game folder for the cache, so the full-size texture is shown.
- When a texture's cache really isn't there, the texture's description says so, with the size actually shown: for example *2048 x 2048, BC1, 12 mips (showing 64 x 64; Textures.tfc with the larger ones wasn't found)*.

## Windows
- **`DarkSTL_0.26.1_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.26.1_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.26.1-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```
