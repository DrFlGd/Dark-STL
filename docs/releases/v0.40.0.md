## What changed
- **Redraw preview.** Right-click a model's card (or open ⋯ on its page) and choose *Redraw preview*: its picture is drawn again with what Dark STL reads now. For previews an earlier version drew without their textures, which stayed because the model's file hadn't changed.
- **Redraw previews for a whole game, kind or group.** Under ⋯ on a game's page (or right-click the game in the sidebar), *Redraw this game's previews*; on a kind or group's page, *Redraw previews here*. They're drawn again as they come into view, and nothing needs rescanning.
- Settings > Previews still has *Draw them again* for every game at once.

Tested on byte-built Dark Souls III files.

## Windows
- **`DarkSTL_0.40.0_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.40.0_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.
