**DOOM Eternal's models, textures and animations, read straight from the game.**

## What changed
- **DOOM Eternal in the library.** Add the game's install folder as it is: Dark STL reads the `.resources` containers and `.streamdb` files in `base` (the first scan reads through them once) and lists the demons, the Slayer and other characters, the weapons, pickups and props, and map pieces, grouped by their folders. Where the game keeps several copies of a file (a patch over the original), the current one is used, as the game's own `meta.resources` says.
- **Textures and materials.** Each surface's colour, normal and specular maps come from its material (`material2` decls, parents included), at full size from the StreamDB. They show on the Textures tab and are used by Displace like any other game's.
- **Posing.** Skinned models (`.md6mesh`) come with their skeleton, and every animation made for that skeleton is on the Pose tab.
- **Oodle.** DOOM Eternal compresses its files with Oodle. Dark STL uses the game's own `oo2core_8_win64.dll` (beside `DOOMEternalx64vk.exe`) and finds it by itself; the folder says so if it's missing, and *Settings › Game tools › Oodle* can point to it.
- **Collect works without the game.** *Game files* writes each model's resources and streamed pieces decompressed, so the collected copy needs neither the game nor Oodle; model packages work as for every other game.
- **Size and normal maps still to be checked on the real game.** Everything was tested on synthetic files built to the published descriptions of the formats (Valen's). Models are scaled from id units as inches; if a model comes out the wrong size, a game profile in the settings folder (*Settings › Game tools › Game profiles*) can change it: `{"format": 1, "name": "DOOM Eternal", "engine": "idtech", "idtech": {"unit": 0.01}}`, or whatever fits (docs/profiles.md). Models are named by their file names for now; in-game names come later.

DOOM (2016) and DOOM: The Dark Ages follow in the next releases.

## Windows
- **`DarkSTL_0.53.0_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.53.0_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.53.0-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```
