**Borderlands 2 gun skins show their colours.**

## What changed
- Borderlands 2 and The Pre-Sequel have no colour texture for a gun skin: the game's `Master_Gun` shader mixes the colour at run time from the skin's zone colours (midtone, highlight, shadow for zones A, B and C), its masks, pattern and decal, and the weapon type's detail texture. Dark STL now reads those values from the skin's material instance chain and bakes the same mix into a colour texture for each part of the gun.
- Nothing is made up front. A part's colour is baked the first time it's shown (opening a configured gun with a skin, or its Textures tab), and kept in the app's cache (`gunpaint` folder), so the next time it opens straight away. A changed skin or game file makes a new bake.
- The skin's masks and detail texture are no longer shown as if they were colour and specular maps, and the parts keep their own normal maps where the skin has none.
- Left out: the environment reflection (it depends on the view) and the game's lighting. The shader reading follows BL2_ReBased's weapon paint model (MIT licence, zuhuHix and the OpenWillow contributors).

Tested on synthetic packages; not yet checked on the game's own skins.

## Windows
- **`DarkSTL_0.23.0_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.23.0_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

pip install "dark_stl-0.23.0-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
