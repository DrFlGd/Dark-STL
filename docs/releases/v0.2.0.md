Dark STL is now a proper Windows app, built with Tauri, and it includes the isotropic remesher.

## Windows
- **`DarkSTL_0.2.0_x64-setup.exe`** installs Dark STL for your account (no administrator rights) with a Start menu entry. It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.2.0_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.
- No Python needed, as before.

## What changed
- **An app, not a page.** Dark STL is a Tauri app, like Model Library. Its engine (the readers, the remesher, the exporters) runs as a hidden process that the window talks to directly, so there is no local web server, no port and no browser.
- **One program at the top.** The app's folder holds `Dark STL.exe`; the engine lives in the `engine` folder beside it. `engine\darkstl.exe` is also the command line (`scan`, `info`, `textures`, `export`, `enhance`).
- **The isotropic remesher is in.** *Enhance > Method > Isotropic remesh* gives an exact vertex count of evenly sized triangles. Only the parts of VTK it needs are included, so the app stays a reasonable size.
- If the app has a problem, `%LOCALAPPDATA%\DarkSTL\cache\darkstl.log` says why.

## Checked
Every release's Windows app is installed with its installer and driven on GitHub's Windows machines: the game library with previews, a model opened with its textures, enhanced with the isotropic remesher, and exported as STL.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.2.0-py3-none-any.whl[gui,remesh]"
darkstl
```
