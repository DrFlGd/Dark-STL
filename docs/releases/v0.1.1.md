Dark STL now comes as a Windows program: no Python needed.

## Windows
- **`DarkSTL_0.1.1_x64-setup.exe`** installs Dark STL for your account (no administrator rights) with a Start menu entry. It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.1.1_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.
- Both include `darkstl.exe`, the command line (`scan`, `info`, `textures`, `export`, `enhance`).
- Windows 10 or 11, 64-bit. The app window uses Microsoft Edge WebView2, which Windows already has; without it the app opens in your web browser instead. If the app won't start, `%LOCALAPPDATA%\DarkSTL\darkstl.log` says why.
- The Windows app leaves out the optional isotropic remesher (it would make the app several times the size). Enhance uses adaptive subdivision, the default, as before; install from source if you want the remesher.

## Fixed
- Without a usable app window, `--port` made the app stop instead of opening in the browser.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.1.1-py3-none-any.whl[gui,remesh]"
darkstl
```
