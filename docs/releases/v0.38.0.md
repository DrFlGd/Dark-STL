**Posing Borderlands 2 characters with the game's own animations.**

## What changed
- **Borderlands 2 characters can be posed.** Characters, heads and creatures from Borderlands 2 (and Borderlands and The Pre-Sequel, which keep animations the same way) now get the Pose tab, with the sequences of every `AnimSet` in the game made for the model's bones, listed as *AnimSet: sequence*. Pick one and a frame to pose the model, then Generate, cut, finish and export as with the other games.
- **How they're found.** Nothing in the game's packages says which animations a model uses, so Dark STL offers each model every AnimSet whose bones are its bones. The first time you open the Pose tab on a Borderlands model, Dark STL lists the AnimSets of every package in the game and keeps the list. For a folder scanned with an earlier version this reads every package again once, which can take a few minutes; later models list theirs at once. Each AnimSet is read from its own package, or from a map that carries a copy when that is all the game has.
- **Borderlands 2's own key formats are read**: its polar-encoded rotations, its delta-encoded translations and its numbering of per-track formats. The model keeps its own bone lengths unless the AnimSet moves them, as the game plays them, and the character stays in place instead of walking off.
- **Until the game's AnimSets have been listed**, every skeletal model with bones shows the Pose tab. After that, only models that have animations show it. Gun meshes made of parts aren't posed.
- **Collect and model packages keep the animations.** Collect copies the packages a model's AnimSets are read from, so a collected character poses with the game uninstalled. Model packages keep the sampled animations like the other games' do.

Tested on byte-built Borderlands 2 packages (polar-encoded and per-track keys, copies cooked into a map, additive and held poses, Collect with the game removed, model packages). Not yet checked on real game files.

## Windows
- **`DarkSTL_0.38.0_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.38.0_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.38.0-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```
