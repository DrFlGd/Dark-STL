A faster **start-up**: the library no longer sits on *Reading game folders* every time the app opens.

## What changed
- **Unchanged game folders aren't scanned again at start-up.** Each folder's last scan is kept with a quick fingerprint of it (the date of every folder in it, and the size and date of its big archives). At the next start a folder whose fingerprint still matches is used as it is, with what its scan prepared for opening models (the texture index, RE Engine file index) put back straight away. A folder where a file was added, removed or renamed, or an archive changed, is scanned again behind the listing as before. **Rescan** still scans a folder whatever its fingerprint says (use it after overwriting files in place).
- **A scan lists each folder once.** Every importer used to walk the whole folder itself (five walks per folder, two of them asking every file's size); now the first listing is shared. On Windows the sizes come with the listing for free.
- **Cyberpunk's archive names are read when you first open a Cyberpunk model**, from the cache, instead of at start-up.
- **The library overview is worked out once per change** instead of on every request, so the home page stays responsive while a folder is scanned.

On a synthetic library of 90,000 models (an unpacked Elden Ring-style folder and 40 Cyberpunk archives), the start-up job went from 11 s to 0.7 s, and a first scan from 15 s to 11 s. Model previews weren't part of the start-up work: they are drawn only for the cards on screen, on their own workers, and kept until Rescan.
