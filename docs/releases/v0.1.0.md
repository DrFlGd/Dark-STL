The first release of Dark STL: browse the models of your FromSoftware games and turn them into high-detail meshes for printing.

![A model page: the enhanced katana grip in clay](https://raw.githubusercontent.com/DrFlGd/Dark-STL/v0.1.0/docs/images/model-page.png)

## What it does
- **A library per game.** Add your game folders (or folders of extracted files) and browse each game's models by kind: weapons, armour, characters, faces and hair, objects, map pieces. Previews, search, sorting, and Model Library's skins and themes.
- **A model page.** See the model in 3D, textured, as clay or as wireframe; leave parts out; look through its textures and materials.
- **Enhance.** Space the vertices evenly up to an exact count, raise the detail stored in the normal maps into real geometry, and export STL, OBJ with textures, PLY or GLB, in millimetres.
- **Command line.** `darkstl scan`, `info`, `textures`, `export` and `enhance` do the same without the window.

## Install
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.1.0-py3-none-any.whl[gui,remesh]"
darkstl
```

`gui` opens the app in its own window (without it, `darkstl gui --browser` opens it in your browser). `remesh` adds the optional isotropic remesher. See the README for getting the game files.
