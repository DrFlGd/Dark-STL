Stair-stepped edges in normal maps are now smoothed before upscaling, so they no longer turn into jagged relief, and a normal map upscaled in another program can be brought back in for displacement.

## What changed
- **Jagged edges smoothed.** Edges a normal map was baked with too few pixels for come out as stair-steps, and an upscaler keeps them: at 4x, and just as much at 8x or 16x, it only makes the steps bigger. The Textures tab now has **Jagged edges** (under *Compression clean-up*): each edge that runs at an angle to the pixel grid is blended along its own length, following its curve, before the map is upsampled, so it stays as sharp across as before but runs smoothly. Grain, noise and edges running straight along the grid are left as they are. On a test map with stair-stepped edges this cuts the error along the edges by about a third with the AI upscaler (and the AI no longer draws ripples along the steps); on clean maps it changes almost nothing. It is on by default; *Smooth lightly* does half as much and *Leave as they are* turns it off. Maps already upscaled are made again with it the next time.
- **Use your own upscaled normal map.** Save a texture (*Save as PNG*), upscale it in any program you like, and bring the result back: each map in the Textures tab has **Use my own upscaled file…** (PNG, TGA, TIFF, DDS, JPEG, WebP or BMP). The file is used as it is for that map, in place of the clean-up and upsampling settings, and Displace reads it. It has to be the texture's shape made bigger (a size that isn't a whole multiple is resized to the nearest one). A flipped green channel is put right, and a file that doesn't look like the texture gets a warning. The choice is kept per model; *Stop using it* goes back to the settings. Replacing the file with a new version is picked up next time.
- The command line takes `--edge-smoothing 0..1` (default 1) and `--use-map TEXTURE=FILE`.

## Windows
- **`DarkSTL_0.6.1_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.6.1_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.
