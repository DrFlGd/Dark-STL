**Returnal normal maps are found automatically.**

## What changed
- Returnal keeps its normal maps as `_Comp` textures: the normal in red and green, a mask in blue. Dark STL now takes a Returnal `_Comp` texture as the material's normal map (Displace and the upscaler read only red and green, so the mask doesn't disturb them). `_Metalness` counts as a mask map in every game.
- When a material names its colour map but not its normal map (or the other way round), Dark STL now looks beside it in the game's files for the texture with the same name and the other role: `T_Gun_BaseColor` found, `T_Gun_Normal` (or `_N`, `_NRM`, `_Normals`...) in the same folder is taken as its normal map. On Returnal, the colour maps were found but the normal maps weren't, so Displace had nothing to read. This applies to every Unreal game.
- More names count as normal maps: `_Normals`, `_NormalMap`, `_NRML`, `_NML`, `_NOR`, `_NRMA`, `_NR`.
- Each material on the Textures tab now has **How its textures were found**, which lists the parameters and textures Dark STL read for it, and any it couldn't read. If a model still gets the wrong texture, that list shows why.
- You can also pick any texture yourself with **Change…** beside a material's normal map (the texture picker, since 0.28.0).

Tested on synthetic unversioned Returnal packages whose material names only the colour map, with the normal map beside it under five naming styles (`_Comp`, `_Normal`, `_N`, `_Normals`, `_NRM`). `_Comp` counts as a normal map only for Returnal.
