**Collect imports models as model packages, which open without the game.**

## What changed
- Collect has a new **Save as** choice, set to **Model packages**. Each model is written once into Dark STL's library folder (`<game> packages`, beside the collected copies), as a folder named after its file in the game holding:
  - a glTF file (`.glb`) with the mesh, one piece per part and material, its UVs and shading normals, and its **skeleton and skin weights**. Blender and other tools open it as it is.
  - a description of the model: materials and which texture is each one's colour, normal or height map, how its normal maps are made, sockets, notes, and its **animations**.
- Textures and animations go into the game's **asset store** (`assets/` beside the packages), each kept once. Textures keep their names from the game; animations are stored as the pose of every bone at every frame, so models that share animations share the files.
- Packages are listed and opened like any other model: Generate, Cut, Finish, Paint, Export and the **Pose tab** all work on them with the game removed from the library or uninstalled. When a model has a package and is also in the game's folder, the library shows the package.
- Weapons with parts and skins (Configure tab) are still copied as game files when importing, so their parts and skins can still be chosen. Choose **Game files** to copy everything the old way.

This is the first stage of the plan to separate the importers from the editing side. Next: a texture picker (search the stored textures by name and assign one to a material slot), then the library overlay (your own folders, in-game names, combined face/body/hair), then saved variations of generated models.

Tested on synthetic files for every game the app reads (Dark Souls III, Borderlands 2, Cyberpunk 2077, Resident Evil 2 and 4, Wonderlands, Borderlands 4, Returnal): every model imported, the game moved away, and each model, texture, animation list and pose compared with what the game showed. Not yet tried on real installs, so the time and space a whole game's animations take are untested.

## Windows
- **`DarkSTL_0.27.0_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.27.0_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.
