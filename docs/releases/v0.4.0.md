Characters and other animated models can now be posed: pick one of the model's animations, step to a frame, and generate and export the model held in that pose. And models can be collected into the app, so a game's install isn't needed once its models are copied.

## What changed
- **Collect into the app.** A game's ⋯ menu, a kind's or group's details, a model's right-click menu and the model page's ⋯ menu have *Collect into the app…*: it copies the files the chosen models need (the model archive, its textures and split texture packs, its animations, and if you want the player's animations and the low-detail copies too) into Dark STL's own library folder, laid out like the game's folder. The dialog says what would be copied, how large it is and what is already there before anything is copied. Collected models are listed under their game like any other folder (a model in both places is listed once), so the game's folder can be removed from the library or the game uninstalled and the models stay, textures and poses included. Settings gets an **App library** section: where the copies are kept, how much is there, and a button to show the folder.
- **Pose tab.** A model whose animations are beside it (`c1120.anibnd.dcx` next to `c1120.chrbnd.dcx`, the split `_divXX` / `_aXX` archives of the later games, or an unpacked `-anibnd-dcx` folder) gets a Pose tab: find an animation, drag the frame slider, step a frame at a time or play it through, and go back to the bind pose. The 3D view shows the pose; the stage bar names it.
- **Generate and Export use the pose shown.** A generated model remembers which pose it was made in, so switching between poses you have already generated is instant, and the export name carries the animation and frame (`c1120_a000_003000_f60.stl`).
- **Havok animation files are read directly:** packfiles (Bloodborne, Dark Souls III and Dark Souls PTDE) and tagfiles (Dark Souls Remastered, Sekiro, Elden Ring with its `.compendium`), spline-compressed and interleaved animations. Nothing else is needed.
- **Command line:** `darkstl info` lists a model's animations; `darkstl export ... --pose a000_003000@60` exports a frame.

Checked on Bloodborne's `c1120` (all 82 animations decode) and Dark Souls Remastered's `c2240` skeleton. Other games' files follow the same formats but haven't been tried on real files yet; a model whose animations can't be read says so in the Pose tab, and still works in its bind pose.

## Known limits
- Cloth and hair that the game simulates stay in their bind pose. Root motion is left out, so the model stays in place.
- Armour pieces have no animations of their own; copy the player's `c0000.anibnd.dcx` next to a part to pose it.

## Windows
- **`DarkSTL_0.4.0_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.4.0_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

pip install "dark_stl-0.4.0-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
