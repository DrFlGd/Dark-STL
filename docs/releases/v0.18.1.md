**Borderlands 2 and The Pre-Sequel guns now come with their textures**, and the gun configurator is easier to find.

## What changed
- **Gun skins.** The shared gun meshes in `Startup.upk` only carry placeholder materials: the game paints each gun with the skin its Material part names (`GD_Weap_Pistol.ManufacturerMaterials.Mat_Jakobs_1` and the like). Each configurable gun (*Pistol (any parts)*, *Shotgun (any parts)*...) now has a **Skin** choice listing every skin the game's part definitions give that weapon type. The chosen skin goes in the guns' first material slot, as in the game, and its textures appear in the Textures tab and in Displace. The default skin is the one from the default body's maker.
- **Finding the configurator.** The configurable guns are listed under *Weapons* as their own cards ("Configurable: N slots, M parts"). Opening the shared mesh itself (`Pistol_Gestalt`...) now shows a **Configure** tab with a button that opens the gun to configure, and the mesh's notes say so.
- **Configuration lists** take `"kind": "material"` on a slot, for choices that change what a model is painted with rather than adding a part (see `docs/configurations.md`).

Built and tested on synthetic packages made to the published layouts; not yet checked on the game's own files.

## Windows
- **`DarkSTL_0.18.1_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.18.1_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.18.1-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```
