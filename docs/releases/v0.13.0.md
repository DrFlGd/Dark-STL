Resident Evil characters can now be **posed with the game's own animations**, and the games open **straight from their install folder**: the community file lists that name the files in their `.pak` archives come with Dark STL, so there's no `.list` file to find and copy in any more.

## What changed
- **Pose tab for RE Engine models.** A character with bone weights lists the animations from the game's `.motlist` files filed under its id (`pl0000`, RE4's `cha0` folder for `cha000_00`, Village's `ch01`...), read from the paks or an extracted folder. Pick one and a frame and the model is posed for Generate, Export and the previews, as for FromSoftware models. Only motion files that move the model's bones are offered; the character's own animations come first in the game's folders, cutscenes after. What each file holds is remembered, so the list comes back quickly the next time.
- **Collect** copies the motion files a character's animations come from along with it (untick Animations to leave them out).
- **RE Engine file lists included.** Ekey's lists from [REE.PAK.Tool](https://github.com/Ekey/REE.PAK.Tool) for Resident Evil 2, 3 and 7 (the ray-tracing and the original releases), Resident Evil 4, Village and Devil May Cry 5 are bundled, cut down to the files Dark STL reads (meshes, textures, materials and animations: 1.6 MB in all). Add the game's install folder and its models are listed from the paks. A `.list` file in the game's folder is still read as well, for files a game update added after these lists.
- The folder note for a pak no list names now says the game may have been updated and where newer lists are.

Posing RE models has only been tried on test files made to the format's description, not yet on the games' own animations. If a pose comes out wrong, the model and animation names help.

## Windows
- **`DarkSTL_0.13.0_x64-setup.exe`** installs Dark STL for your account (no administrator rights). It isn't signed, so SmartScreen asks once: *More info > Run anyway*.
- **`DarkSTL_0.13.0_x64-portable.zip`** is the same app in a folder: unzip it anywhere and run `Dark STL.exe`.

## Other systems
Python 3.10 or newer. Download the wheel below, then:

```
pip install "dark_stl-0.13.0-py3-none-any.whl[gui,remesh,fast,ai]"
darkstl
```
