File lists for reading RE Engine .pak archives
==============================================

Pak archives store only a hash of each file's path, so file names come from lists the
RE Engine modding community keeps. The lists here are Ekey's, from REE.PAK.Tool
(https://github.com/Ekey/REE.PAK.Tool, Projects/*.list, commit
d22c15314e84eecd31480acfe692092c48043ac0), cut down to the files Dark STL reads (.mesh, .tex,
.mdf2, and the .motlist and .mot animations) and gzipped. All credit for them goes to Ekey and the people who worked out the
names. A .list file put in a game's folder is read as well, so a newer list can be dropped in
there after a game update.
